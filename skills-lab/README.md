# Skills lab material

Supporting files for **section 6.7 – Hands-on lab: build your first Agent Skill** in [`docs/workshop.md`](../docs/workshop.md). Follow the steps there; this folder only holds the inputs.

| Folder | Contents |
| --- | --- |
| `scenarios/` | Fictional incident notes used as the lab input |
| `resources/` | Short primers, the handoff acceptance criteria and the skill quality checklist |
| `solutions/` | A reference `incident-handoff` skill. Compare against it **after** you finish testing your own |

The reference solution deliberately lives here and **not** in `.github/skills/`, so Copilot does not discover it while you build your own skill.

All data is fictional. Do not add real incidents, customer data, credentials or internal URLs.

Adapted from [Build Your First GitHub Copilot Skill](https://github.com/annawiewer/Skill_hands-on) by Anna Wiewer.
